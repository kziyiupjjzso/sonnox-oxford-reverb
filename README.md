## Overview

Sonnox Oxford Reverb is a professional algorithmic reverb with accurate room modeling, separate early and late reflection shaping, and transparent processing quality.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sonnox Oxford Reverb** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Room Modeling** | Accurate early reflection patterns for specific room geometries |
| **Decay Shaping** | Independent attack, hold, and decay for each reverb section |
| **Pre-Delay** | Up to 600 ms pre-delay for large, epic reverb spatial placement |
| **Transpose** | Pitch transpose of reverb tail for harmonically interesting textures |
